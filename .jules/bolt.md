## 2026-11-05 - Throttle Window Scroll Handlers with requestAnimationFrame Ticking
**Learning:** Attaching unthrottled DOM mutations (like `element.classList.toggle` or `add/remove`) inside raw `window.addEventListener('scroll')` handlers triggers unnecessary script execution and style recalculations on every mouse wheel tick or trackpad gesture (often 60–120+ times per second). Even with `{ passive: true }`, mutating classes and inspecting DOM state repeatedly in the same render frame causes main thread overhead.
**Action:** Use a `requestAnimationFrame` ticking flag (`let isTicking = false;`) and check existing class state before mutating the DOM. This limits class updates to at most once per display refresh cycle (16.7ms @ 60Hz) and avoids unnecessary DOM writes when the target class state hasn't changed.
