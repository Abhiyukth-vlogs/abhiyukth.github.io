## 2026-03-31 - Hoisting Math.sin/cos and Vector Allocations in 3D WebGL Animation Loops
**Learning:** In Three.js grid animations (such as 55x55 BufferGeometry vertex wave loops), calculating `Math.sin(gx * scale + t)` and `Math.cos(gz * scale + t)` inside nested inner loops triggers 6,000+ trigonometric calls per frame. Because $X$ depends only on column index $i$ and $Z$ depends only on row index $j$, pre-calculating values per row/column reduces trig calculations per frame to 110 (98.2% reduction). Additionally, allocating `new THREE.Vector3(...)` inside 60 FPS lerp loops creates heap allocation churn (~180 objects/sec).
**Action:** Always hoist 1D coordinate transformations out of 2D grid loops and use static/reusable vectors (`tempScaleVec.setScalar(...)`) for per-frame lerp transforms.
